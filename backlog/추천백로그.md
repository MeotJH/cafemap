
## 메인페이지 변경
개인별 큐레이션에 맞춰서 조금 더 나은 리스트를 보이기 위해서 해당 리스트를 추가한다.

상황별 추천 카페
데이트 / 대화 / 사진 / 커피맛 / 오래 앉기

그래서 하단의 버튼(뱃지?) 중에 하나를 선택하면
랭크 페이지로 가고 데이트에 좋은 카페( 분위기 및 커피맛 )
대화에 좋은 카페 ( 분위기 및 친절도 )
사진 ( 분위기 및 화장실 좋음)
커피맛 ( 커피맛 좋은곳 )
오래 앉기 ( 콘센트 와이파이 친절도 )
랭크를 보여준다.

오늘의 부부픽은 어떤 구조로 지금 만들어지는지 확인해야 한다.


## 카페부부 지도 요소 기획변경
“우리가 다녀온 카페 위치”
에서 끝나는 게 아니라
“내가 지금 있는 곳 근처에서 부부가 추천한 카페”
를 찾게 해야 합니다.

내 주변 부부픽	현재 위치 근처 추천 카페
지도 이동 후 검색	성수/잠실/연남으로 지도를 옮기면 해당 지역 카페 표시
반경 필터	1km / 3km / 5km
카페 카드 연동	마커 클릭 시 사진, 한줄평, 아내평, 남편평 표시


## 맛집/카페 서비스 지도는 “필터”와 같이 씁니다

테이블링은 맛집 검색에서 근처 맛집, 음식 종류별 맛집, 추천 맛집, 찜하기 기반 개인 맛집 지도 같은 식으로 지도/위치/검색을 결합합니다. 웹에서도 한식, 일식, 양식, 카페/베이커리, 지역별 인기 웨이팅 맛집처럼 목적별 진입점을 제공합니다.

카페부부에 필요한 필터는 음식점 필터가 아니라 카페 감성 필터입니다.

추천 필터

커피 취향	고소함 / 산미 / 라떼 / 핸드드립 / 아메리카노
