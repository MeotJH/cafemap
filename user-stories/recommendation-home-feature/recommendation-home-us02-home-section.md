# US-02: 홈에 상황별 추천 섹션 노출

## 사용자 스토리

방문자로서 홈에서 바로 카페 방문 목적을 선택하고 싶다. 그래야 랭킹 메뉴를 직접 탐색하지 않아도 원하는 추천 목록으로 갈 수 있다.

## 범위

- 홈 화면에 `상황별 추천 카페` 섹션을 추가한다.
- 5개 목적 버튼 또는 칩을 노출한다.
- 각 항목은 라벨과 짧은 보조 문구를 가진다.
- 기존 `아내픽 TOP 3`, `남편픽 TOP 3`, `오늘의 부부픽` 흐름은 유지한다.

## 배치 제안

- `아내픽 TOP 3`와 `남편픽 TOP 3`보다 위에 둔다.
- 홈의 주요 진입점 역할이므로 첫 화면에서 보이거나, 히어로 바로 아래에 둔다.

## 프론트 영향

- `front/lib/presentation/pages/home_page.dart`
- 목적 정의를 위한 작은 모델 또는 상수 파일
- 목적 칩/카드 위젯

## 백엔드/계약 영향

- 홈 섹션 자체는 정적 UI로 시작 가능하다.
- 목적별 카페 미리보기까지 홈에 넣는 경우 `/home` 응답 확장이 필요하므로 1차 범위에서는 제외한다.

## 역할별 할 일

### Frontend

- 홈 화면에 `상황별 추천 카페` 섹션을 추가한다.
- 목적 카드 또는 칩 UI를 구현한다.
- 작은 화면에서도 줄바꿈과 터치 영역이 무너지지 않게 조정한다.

### Backend

- 1차 범위에서는 추가 작업 없음.
- 이후 홈 미리보기를 넣을 가능성에 대비해 `/home` 응답 확장 필요 여부를 판단한다.

### Designer

- 섹션 위치를 홈의 어느 구간에 둘지 확정한다.
- 카드/칩의 라벨 우선순위, 보조 문구 길이, 시각적 강조 수준을 정한다.

## 수용 기준

- 홈에 5개 목적이 모두 보인다.
- 각 목적 항목은 터치 가능한 상태로 보인다.
- 기존 홈 섹션은 사라지지 않는다.
- 작은 화면에서도 텍스트가 잘리지 않는다.

## 검증 메모

- `flutter analyze`
- 홈 화면에서 5개 목적 노출과 클릭 가능 상태를 확인한다.
