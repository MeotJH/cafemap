# 3. 맵 화면 검색 이력 UX

## 목표
- 맵 화면 검색 입력창을 눌렀을 때 최근 검색 이력을 바로 다시 선택할 수 있게 한다.
- 검색어 재입력 없이 빠르게 재검색할 수 있게 한다.

## 요구사항
- 맵 화면 검색 `TextField` 포커스 시 흰색 모달 UI를 보여준다.
- 모달에는 사용자의 최근 검색어 리스트를 최신순으로 노출한다.
- 최근 검색어 항목을 누르면:
  - 검색창에 해당 검색어를 채운다.
  - 즉시 동일 검색 로직을 실행한다.
- 최근 검색어는 중복 저장하지 않는다.
  - 같은 검색어를 다시 검색하면 맨 위로 올린다.
- 리스트는 최대 개수 제한을 둔다.
  - 기본안: 최근 10개
- 전체 삭제 버튼 제공 여부 검토
  - 기본안: 제공

## UI 방향
- 검색창 아래 드롭다운 느낌보다, 화면 상단에 붙는 흰색 모달/패널 형태가 적합하다.
- 항목 구성:
  - 최근 검색 아이콘
  - 검색어 텍스트
  - 개별 삭제 아이콘은 선택사항
- 빈 상태 문구:
  - `최근 검색어가 없어요.`

## 기술 메모
- 프론트 저장 위치:
  - `shared_preferences` 또는 로컬 캐시 provider
- 추천 구현 위치:
  - `front/lib/presentation/pages/map_home_page.dart`
  - 필요 시 검색 이력 전용 유틸/서비스 분리
- 상태 관리:
  - 입력 포커스 여부
  - 최근 검색어 리스트
  - 모달 open/close 상태

## 수용조건
- 검색창을 탭하면 최근 검색 패널이 열린다.
- 최근 검색어를 누르면 새 검색이 정상 실행된다.
- 같은 검색어를 여러 번 검색해도 중복 항목이 쌓이지 않는다.
- 검색 결과 선택 후 다시 검색할 때도 최근 검색 패널이 정상 동작한다.
