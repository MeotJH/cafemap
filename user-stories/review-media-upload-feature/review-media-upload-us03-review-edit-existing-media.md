# US-03: 리뷰 수정 화면의 기존 미디어 유지/삭제/추가

## 사용자 스토리

기존 리뷰를 수정하는 사용자로서 이미 올린 사진/영상은 유지하고, 일부만 지우거나 새 미디어를 추가하고 싶다.

## 범위

- 수정 화면에서 기존 미디어와 신규 미디어를 함께 보여준다.
- 기존 미디어 삭제와 신규 미디어 추가를 같은 세션에서 처리한다.
- 전체 첨부 수는 기존+신규 합산 최대 5개를 유지한다.

## Frontend Tasks

- 기존 `existingImageUrls` 모델을 기존 미디어 항목 목록으로 일반화한다.
- 기존 항목과 신규 항목을 하나의 갤러리에서 렌더링한다.
- 삭제 시 실제 서버 반영 방식에 맞춰 payload를 재구성한다.
- 영상이 포함된 기존 리뷰의 수정 진입 초기화 로직을 추가한다.

## Backend Tasks

- 수정 API가 "유지할 미디어 목록" 기준으로 동작할지, "전체 미디어 목록 교체" 기준으로 동작할지 정한다.
- 기존 이미지 리뷰도 수정 응답에서 새 미디어 모델로 일관되게 반환한다.

## Designer Tasks

- 기존 항목과 신규 항목의 구분이 필요하면 시각 규칙을 정한다.
- 삭제 예정 상태, 업로드 대기 상태, 업로드 완료 상태를 정한다.

## 계약 및 의존성 노트

- update payload 정책이 선행되어야 한다.
- "기존 미디어 삭제"가 실제 파일 삭제까지 의미하는지, 참조만 제거하는지 백엔드 정책이 필요하다.

## Acceptance Criteria

- 수정 화면에서 기존 사진/영상이 표시된다.
- 일부 삭제 후 새 항목을 추가해도 총 5개 제한이 일관되게 적용된다.
- 저장 후 상세 화면에 수정 결과가 정확히 반영된다.

## Verification Notes

- 이미지만 있는 기존 리뷰
- 영상만 있는 리뷰
- 이미지/영상 혼합 리뷰
- 삭제 후 재추가 시나리오를 각각 확인한다.
