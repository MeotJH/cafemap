# US-03: 홈 목적 선택 시 랭킹 페이지 이동

## 사용자 스토리

방문자로서 `데이트` 같은 목적을 누르면 해당 목적의 카페 랭킹으로 이동하고 싶다. 그래야 목적에 맞는 추천을 바로 볼 수 있다.

## 범위

- 홈의 목적 항목을 누르면 랭킹 화면으로 이동한다.
- route query에 목적 key를 전달한다.
- 예: `/rankings?purpose=date`
- 선택한 목적은 랭킹 화면에서 유지된다.

## 프론트 영향

- `front/lib/app/router.dart` 확인 후 기존 랭킹 route 구조에 맞춰 query parameter를 연결한다.
- 홈 목적 항목의 `onTap`에서 `context.push` 또는 기존 네비게이션 패턴을 사용한다.

## 백엔드/계약 영향

- 이 스토리 자체는 프론트 route 연결만 포함한다.
- 실제 정렬 데이터는 `US-05` 이후에서 처리한다.

## 역할별 할 일

### Frontend

- 홈 목적 항목 클릭 시 `/rankings?purpose=...`로 이동시킨다.
- 뒤로가기 시 홈으로 자연스럽게 돌아오도록 기존 router 패턴을 유지한다.

### Backend

- 직접 작업 없음.
- 이후 `purpose` query parameter가 실제 API와 연결될 수 있도록 key 규칙만 유지한다.

### Designer

- 카드 또는 칩이 눌렸을 때 사용자가 랭킹으로 이동할 것으로 기대할 수 있게 상호작용 힌트를 준다.

## 수용 기준

- `데이트` 선택 시 랭킹 화면에 `purpose=date` 상태가 전달된다.
- 브라우저 뒤로가기 또는 앱 뒤로가기로 홈으로 돌아올 수 있다.
- 잘못된 목적 key가 들어와도 화면이 깨지지 않는다.

## 검증 메모

- 홈에서 각 목적을 눌렀을 때 query parameter가 달린 route로 이동하는지 확인한다.
