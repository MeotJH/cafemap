# US-02: 리뷰 작성 화면의 혼합 미디어 첨부 UI

## 사용자 스토리

리뷰 작성자로서 사진과 영상을 같은 첨부 영역에서 관리하고 싶다. 그래야 어떤 형태로든 리뷰 근거를 빠르게 올릴 수 있다.

## 범위

- 리뷰 작성 화면의 첨부 영역을 사진/영상 공용 영역으로 바꾼다.
- 사용자는 사진 또는 영상을 선택해 추가할 수 있다.
- 현재 첨부 수와 최대 수를 함께 보여준다.
- 영상 항목은 썸네일과 재생 표시를 가진다.

## Frontend Tasks

- `review_write_page`의 첨부 로직을 `selectedMediaItems` 중심으로 재구성한다.
- 웹/모바일에서 이미지와 비디오 선택 흐름을 분리하거나 통합한다.
- 첨부 수 계산을 `existing + selected` 합산 기준으로 바꾼다.
- 영상 선택 시 길이/타입/용량 사전 검사를 넣는다.
- 업로드 전 미리보기 UI에서 이미지/영상 타입별 렌더링을 분기한다.

## Backend Tasks

- 없음. 이 스토리는 클라이언트 입력 UX 중심이다.
- 다만 이후 API 변경 전까지 임시 mock/fallback 구조가 필요하면 지원한다.

## Designer Tasks

- 첨부 CTA를 "사진/영상 추가" 또는 분리 액션 중 하나로 정한다.
- 영상 썸네일 오버레이, 삭제 버튼 위치, 개수 표기 위치를 정한다.
- 제한 도달 상태와 업로드 중 상태를 설계한다.

## 계약 및 의존성 노트

- 실제 업로드는 US-04 계약이 필요하다.
- 1차 UI는 썸네일 생성 정책이 미정이어도 플레이스홀더로 먼저 개발 가능하다.

## Acceptance Criteria

- 사용자가 사진과 영상을 첨부할 수 있다.
- 첨부 개수는 사진/영상 합산 최대 5개로 막힌다.
- 영상 항목은 이미지와 시각적으로 구분된다.
- 제한 초과 시 사용자에게 이유가 명확히 표시된다.

## Verification Notes

- `flutter analyze`
- 웹/모바일 각각에서 사진만, 영상만, 혼합 첨부 흐름을 수동 확인한다.
