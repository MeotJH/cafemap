# 4. 내 활동 화면 지역별 리뷰 그룹핑

## 목표
- 사용자가 어디 지역에서 어떤 리뷰를 남겼는지 한 번에 이해할 수 있게 한다.
- 현재 단순 리뷰 나열 대신 지역 기준으로 그룹핑해 맥락을 강화한다.

## 요구사항
- 내 활동 화면에서 내 리뷰를 지역별로 묶어 보여준다.
- 예시:
  - 중랑구
  - 어디 리뷰
  - 어디 리뷰
  - 종로구
  - 어디 리뷰
  - 어디 리뷰
- 지역 기준은 주소 파싱 또는 저장된 주소 데이터 기준으로 정한다.
- 각 그룹 안에는 작성한 리뷰 카드 또는 간단 리스트를 노출한다.

## 기본 표시안
- 그룹 헤더:
  - `중랑구`, `종로구`, `강남구` 등
- 그룹 내부 항목:
  - 매장명
  - 메뉴명 또는 한 줄 코멘트
  - 작성일
- 그룹은 리뷰 수가 많은 지역부터 또는 최신 리뷰 포함 지역 우선 정렬
  - 기본안: 그룹 내부 최신순, 그룹도 최신 리뷰 기준 정렬

## 기술 메모
- 프론트 구현 위치:
  - `front/lib/presentation/pages/my_activity_page.dart`
- 필요 데이터:
  - 리뷰별 주소 또는 store address
  - 지역명 추출 로직
- 백엔드 변경 필요 여부:
  - 현재 응답에 주소가 충분하지 않으면 API 응답 확장 필요
- 파싱 우선순위:
  - `서울특별시 종로구 ...` -> `종로구`
  - `경기도 성남시 분당구 ...` -> `분당구`
  - 시/군/구 기준이 애매하면 보조 규칙 필요

## 수용조건
- 내 활동 화면에서 리뷰가 지역 헤더 아래 그룹핑되어 보인다.
- 같은 지역 리뷰는 같은 섹션에 묶인다.
- 지역명이 없는 데이터는 fallback 그룹으로 처리한다.
  - 기본안: `기타`
- 기존 리뷰 상세 이동 동작은 유지한다.

## 리스크
- 기존 리뷰 응답에 주소가 없으면 프론트 단독 구현이 어렵다.
- 주소 포맷이 제각각이면 지역 추출 규칙을 별도 유틸로 분리해야 한다.
