# US-08: 사진 목적 점수 계산

## 사용자 스토리

방문자로서 사진 찍기 좋은 카페를 보고 싶다. 그래야 분위기와 비주얼이 좋은 장소를 빠르게 찾을 수 있다.

## 목적 점수 초안

`photoScore = atmosphere + visuals + restroom_cleanliness`

## 사용할 수 있는 현재 데이터

- `atmosphere`
- `visuals`
- `restroom_cleanliness`
- 리뷰 이미지 수

## fallback

- `visuals`는 디저트/음료 카테고리 리뷰에만 있을 수 있다.
- `restroom_cleanliness`는 v2 리뷰에서만 있을 수 있다.
- 점수 데이터가 적으면 리뷰 이미지가 있는 매장을 보조 가산점으로 사용할 수 있다.

## 백엔드 영향

- 목적 점수 계산 함수에 `photo` 분기 추가
- 필요하면 image url count를 보조 신호로 계산한다.

## 역할별 할 일

### Frontend

- 사진 목적 설명과 카드 라벨이 공간/비주얼 추천으로 읽히게 맞춘다.

### Backend

- `photo` 목적 점수를 계산한다.
- 분위기, 비주얼, 공간 상태와 이미지 보조 신호를 반영한다.

### Designer

- `사진` 목적에 기대하는 감성 포인트를 문구로 정리한다.

## 수용 기준

- 분위기 점수가 높은 매장이 사진 랭킹에서 우선된다.
- 비주얼이나 화장실 청결 데이터가 없다는 이유로 매장이 전부 제외되지 않는다.
- 이미지가 있는 매장은 같은 점수에서 우선될 수 있다.

## 검증 메모

- 이미지가 있는 매장과 없는 매장의 동률 처리 방향을 샘플로 확인한다.
