# US-06: 검증, 회귀 점검, 롤아웃 준비

## 사용자 스토리

릴리스 담당자로서 사진 전용 리뷰 흐름이 깨지지 않았는지 확인하고 싶다. 그래야 영상 첨부 확장 후에도 기존 작성/조회 경험을 안전하게 유지할 수 있다.

## 범위

- 기존 사진 전용 흐름 회귀 점검
- 혼합 미디어 작성/수정/조회 E2E 체크리스트 작성
- 운영 전 제한값, 오류 문구, 저장 모델 이행 방식 점검

## Frontend Tasks

- 작성/수정/상세/내 리뷰/매장 리뷰 회귀 체크리스트를 정리한다.
- 실패 상태와 네트워크 지연 상태를 수동 검증한다.

## Backend Tasks

- 리뷰 API, presign API, 스키마 변환 테스트를 보강한다.
- 구형 데이터와 신형 데이터가 같이 있을 때 조회가 일관적인지 검증한다.

## Designer Tasks

- 제한 문구, 오류 문구, 플레이스홀더 표현을 최종 리뷰한다.

## 계약 및 의존성 노트

- 배포 전 데이터 마이그레이션 필요 여부를 결정해야 한다.
- 모바일과 웹의 파일 선택 UX 차이로 인해 검증 기기가 둘 다 필요할 수 있다.

## Acceptance Criteria

- 사진 전용 기존 리뷰 작성/수정/조회가 계속 동작한다.
- 혼합 미디어 리뷰 작성/수정/조회 핵심 시나리오가 통과한다.
- 릴리스 시 주의사항과 후속 개선 항목이 정리된다.
